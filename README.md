# VeloShop — магазин велосипедов на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Учебный каталог велосипедов и аксессуаров, разработанный с использованием Bootstrap 5.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:
- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок;
- блок преимуществ;
- сетка популярных велосипедов;
- подвал.
