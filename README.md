# VeloShop — магазин велосипедов на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Учебный каталог велосипедов и аксессуаров, разработанный с использованием Bootstrap 5.

## Ссылка на опубликованный проект

GitHub Pages: https://admuty.github.io/kr2-bootstrap-shop/

## Подключение Bootstrap

В проекте Bootstrap подключён **локально**. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:
- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог велосипедов;
- `product.html` — страница велосипеда;
- `order.html` — форма заявки;
- `contacts.html` — контакты (дополнительно);
- `css/custom.css` — собственные стили (минимальные);
- `vendor/bootstrap/` — файлы Bootstrap;
- `images/` — изображения;
- `README.md`.

## Реализованные Bootstrap-компоненты

- `navbar` (с выпадающим меню `dropdown`);
- `card` (карточки велосипедов);
- `btn` (кнопки разных вариантов);
- `badge` (метки «Новинка», «Хит», «Скидка»);
- `alert` (информационные сообщения);
- `modal` (быстрая заявка);
- `form-control`, `form-select`, `input-group`, `form-check` (форма заявки);
- `accordion` (частые вопросы);
- `breadcrumb` (хлебные крошки);
- `table` (характеристики велосипеда).

## Самостоятельные доработки

- Bootstrap подключён локально (без CDN);
- добавлена страница `contacts.html`;
