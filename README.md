# VeloShop — магазин велосипедов на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Учебный каталог велосипедов и аксессуаров, разработанный с использованием Bootstrap 5.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:
- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок;
- блок преимуществ;
- сетка популярных велосипедов;
- подвал.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:
- добавлена единая Bootstrap-навигация (с dropdown);
- создана страница каталога `catalog.html`;
- создана страница товара `product.html`;
- создана страница заявки `order.html`;
- использованы компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `input-group`, `form-select`, `form-check`, `accordion`;
- добавлены стили в `css/custom.css`.
